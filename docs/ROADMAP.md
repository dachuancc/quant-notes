# ROADMAP / 项目进度 — quant-notes

> 这是本项目的**唯一状态真相**。每次接手先读这里，再看 `docs/DECISIONS.md`。

## 如何接手（Human & AI）

1. 在项目目录下启动 pi：`cd quant-notes && pi`（pi 自动加载 `AGENTS.md`）。
2. 读本文件 + `docs/DECISIONS.md`。
3. `uv run pytest` 确认 **4 个用例**全绿。
4. 从「下一步」继续。

> ⚠️ 开工前用**新会话**，不要恢复旧会话（旧会话会带回已被推翻的约定）。

## 目标

把量化研究里「**为什么**」的部分沉淀成可检索、可复用、经得起推敲的笔记：

- 与 [`backtest-lab`](https://github.com/dachuancc/backtest-lab) 呼应：笔记讲原理，代码给实现。
- 每篇标注**陷阱**——教科书通常不讲、但实践中代价最大的部分。
- 宁可留 TODO，也不写没有自己思考的填充内容（见 D4）。

**不做**：教程搬运、教科书摘抄、不做原创的"常识汇总"。
