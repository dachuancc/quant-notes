# 夏普比率的定义与陷阱

> **一句话**：夏普衡量"单位波动的超额收益"，但它对**自相关、非正态、样本长度、选择偏差**
> 都极其敏感——它是最被滥用的指标。

## 定义

$$SR = \frac{\mathbb{E}[R - R_f]}{\sigma(R - R_f)}$$

样本估计 $\widehat{SR} = \dfrac{\bar r - r_f}{\hat\sigma}$；日频年化乘 $\sqrt{252}$。

## 关键性质

- **尺度不变**：理论上加杠杆不改变夏普——所以夏普比的是"效率"，不是"收益"。
- **估计噪声极大**（Lo, 2002）。i.i.d. 正态下，年化夏普的标准误约

  $$\mathrm{SE}(\widehat{SR}) \approx \sqrt{\frac{1 + \tfrac12 SR^2}{T_{\text{years}}}}$$

  即：用一个 **夏普 ≈ 1** 的策略，需要约 **6 年**数据才能把标准误压到 0.5。
  **5 年月度数据估出的夏普 1，与 0 在统计上几乎无法区分。**

## 陷阱

1. **自相关**
   收益有正自相关时，$\sqrt{252}$ 年化会**低估波动、高估夏普**；反之亦然。
   需用 Lo (2002) 的自相关修正。

2. **非正态 / 厚尾**
   夏普只用前两阶矩，对**尾部风险无感**。两个策略夏普相同，一个偶发巨亏，
   夏普完全看不出来——这正是"在压路机前捡硬币"。

3. **样本长度**
   见上：夏普的估计噪声与 $1/\sqrt{T}$ 同阶，短样本的夏普基本是噪声。

4. **选择偏差 / 多重检验**
   从 100 个策略里挑夏普最高的那个，它的夏普必然高估（max of noise）。
   需要 **Deflated Sharpe Ratio** 之类的校正。

5. **分母为 0**
   无波动策略夏普未定义（`backtest-lab` 里约定返回 0）。

6. **无风险利率口径**
   用哪个 $R_f$、按什么频率折算，必须与收益频率一致，否则年化会错。

## 补充 / 替代指标

| 指标 | 补了什么 |
|---|---|
| 索提诺比率 | 只惩罚**下行**波动 |
| 卡玛比率 = 年化收益 / \|最大回撤\| | 关注路径与最坏情况 |
| 最大回撤 + 水下曲线 | 直接看"要忍多久" |
| Deflated Sharpe Ratio | 多重检验校正 |
